# 디자인 주문서 — 바이어 리스크 한눈에

> (가상) 한빛정밀(주) 바이어 150곳 · 합성 데이터. 레퍼런스 `ref1.png`(가격표 페이지) · `ref2.png`(작업 대시보드)의 **구조 · 간격 · 글자 위계만** 따라 하고, 색과 내용은 우리 것으로 한다.
> 이 파일의 토큰이 화면에 쓰는 값의 전부다. 토큰 밖 값이 필요하면 먼저 여기에 더한다.

## 1. 레퍼런스에서

**가져올 것**

1. KPI 4칸 한 줄 — 작고 흐린 라벨이 위, 큰 숫자가 아래(ref2 맨 위 카드 줄)
2. 1px 가는 가로줄로 구역과 행을 나누고, 구역 사이는 넓은 여백으로 띄우기(ref1 열 구분 · ref2 표 행)
3. 제목(크게) → 부제 한 줄(작고 흐리게) → 본문의 3단 글자 위계(두 화면 모두)

**가져오지 않을 것**

1. ref2 바깥의 무지개 그라데이션 테두리 · 둥근 큰 프레임
2. 로고 · 아바타 · 아이콘 · 영어 글(메뉴 · 버튼 문구 포함)
3. 레퍼런스 색 — ref1의 주황 버튼, ref2의 파랑 진행 막대와 보라 배지

## 3. 레이아웃 뼈대

순서는 두 폭 모두 같다: **머리 → KPI 4개 → 신호등 등급 분포 + 위험 선 슬라이더 → 위험 상위 10 → 지역별 채권 → 바닥글**

> 지도 추가(7절 ⑥, 사람이 고름): 순서가 **머리 → KPI 4개 → 이번 주 할 일 3 · 대표님이 정할 것 3 → 등급 분포 + 슬라이더 → C등급 채권 상위 10개 나라 지도 → 바닥글**로 바뀐다. 지도는 '위험 상위 10' 표와 '지역별 채권' 막대를 대신한다. 지역 칸은 위치 틀일 뿐 금액을 쓰지 않고, 금액은 나라 카드(C등급 채권 · 연체 · C등급 곳 수)에만 쓴다. 지역 6칸의 배치는 넓은 화면 `"북미 서유럽 중동부유럽 동아시아" / "북미 중동·아프리카 중동·아프리카 동남아"`(4열 격자), 휴대폰은 1열(서 → 동 순서)이다. 지도 그림 · 파일 · 외부 지도 서비스는 쓰지 않는다.

## 4. 'AI 티' 금지 목록

| 금지 | 대신 |
|---|---|
| 보라 · 파랑 그라데이션 | 흰색 · 연회색 바탕 + 강조 1색 |
| 이모지 아이콘 | 글자 라벨, 꼭 필요하면 선 아이콘(SVG) |
| 모든 카드에 그림자 | 1px 테두리나 바탕색 차이 |
| 유리(blur) 효과 남발 | 불투명한 면 |
| 가운데 정렬 일색 | 글은 왼쪽, 숫자는 오른쪽 정렬 |
| 'Welcome back!' 같은 빈말 | 기준일 · 데이터 범위처럼 쓸모 있는 한 줄 |
| 무지개색 차트 | 회색 + 뜻이 있는 1–2색(등급 색) |
| 지나치게 둥근 모서리 | 4–8px |
| 의미 없는 장식 그림 | 빈칸(여백) |
| 영어 더미 글 | 우리말 진짜 문장 |
