## 3. 검사했는데 문제가 없었던 항목

| 검사 | 결과 |
|---|---|
| 잔액 = 다섯 버킷 합계 | B072·B141을 빼면 모두 일치 |
| max_dpd가 가리키는 버킷에 잔액이 있는가 | 150행 모두 일치 |
| TT_ADV(선수금)인데 잔액·연체가 있는 행 | 없음 |
| 국가 → 권역, 국가 → CRC 등급 | 국가마다 값 하나로 일치 |
| 국가 → 통화 | 표기 흔들림만 있고 실제 통화는 맞음 (예: CHN은 USD 또는 CNY) |

## 4. 오류는 아니지만 짚어 둘 점

- **한도 초과 38곳.** USD 환산 잔액이 한도의 1~10배인 바이어가 38곳입니다. 데이터 오류가 아니라 업무 신호이니, 판단은 담당자가 합니다.
- **장기 연체인데 `late_30d=0`.** 라벨 정의가 "기준일 뒤 30일 안에 만기+30일 선을 **새로** 넘음"입니다. 이미 넘은 바이어는 0이 되므로 정의와 일치합니다. 다만 모델을 해석할 때 주의해야 합니다.
- **`map_ccy` 시트가 비어 있습니다.** 헤더(`raw`, `clean`)만 있고 행이 없습니다. dictionary는 통화를 이 시트로 통일하라고 하니, 매핑표는 직접 채워야 할 것으로 보입니다 → 확인 필요.

## 계산 방법

- USD 환산식: 잔액 × (해당 통화의 원화 환율) ÷ (USD 원화 환율)
- 환율은 `fx_at_ref` 시트의 기준일 2026-08-31 값: USD 1368.25 · EUR 1589.50 · CNY 203.62 · JPY 856.55원/100엔
- B072: 8,320,000 × 1589.50 ÷ 1368.25 = 9,665,368 USD → 한도 10,000으로 나누면 966.5배
- 문자열 금액은 콤마 · 공백 · 통화 문자를 지우고 숫자로 읽었고, `k`는 ×1,000으로 읽었습니다(진단용 해석이며 정제 규칙은 아닙니다).
- 진단 코드는 `uv run python`으로 한 번씩 실행만 했고, 아직 `scripts/`에 저장하지 않았습니다.
